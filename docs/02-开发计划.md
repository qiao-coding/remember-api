# 02 · Web 控制台重建开发计划

> **取材来源**：`_legacy/web-plan.md`（旧 W1–W6 周期，本文升级为重建路线）、`web-ux/01-现状审计.md`（欠账排序）、`web-ux/03-页面规格.md`（逐页目标）。
>
> **性质**：重建路线。顺序原则 = **先补基建，再逐页照图施工，后收口验收**。每个里程碑含 目标 / 内容 / 验收。

## M0 · 基建：设计层 + 组件库 + 数据层

**目标**：让后续 11 页都能「拼组件」，消除复制粘贴。

内容（详细契约见 `web-ux/04-组件规范.md`）：
- 设计 token 落地：语义色板 CSS 变量（neutral + 状态蓝/绿/红/琥珀）、间距/圆角/排版刻度；深色语义。
- 主题机制统一：默认跟随系统 + 顶栏手动切换（localStorage），废除 `globals.css` 媒体查询与 Tailwind `dark:` 双机制并存。
- 补齐组件库（`components/ui.tsx` 内）：`Select` / `Field`+`Label` / `Switch` / `Checkbox` / `Dialog` / `ConfirmDialog` / `EmptyState` / `Skeleton` / `PageHeader` / `Spinner` / `Toast` / `CopyButton` / `Pagination`，并补 `Button` 缺失 size。
- 数据层收口：统一 `apiFetch` 封装（复用 `lib/api.ts`）+ 标准化 query key + 通用列表/表单 hook，消灭 6 页重复 CRUD 样板。

验收：
- `components/ui.tsx` 出现上述全部原语，每个有深色态。
- 任一 CRUD 页面能仅靠声明（query key + 端点 + 列定义）重建列表，无手写 `<select>` 样式。
- 全站可切主题，刷新保持。

## M1 · 外壳与全局状态

**目标**：控制台先像一个稳定的开发者控制台（修掉审计里的 P0/P1 外壳问题）。

内容：
- 全局边界：`loading.tsx` / `error.tsx` / `not-found.tsx`；查询错误**不再吞掉**（后端不可用 → 明确报错文案，而非空表）。
- 顶栏全局搜索**接入真实数据**（Profiles / Projects / Memories，跳转对应页带 query 高亮）。
- 深色手动切换入口（顶栏）+ 移动抽屉路由变化自动关闭。
- 文案一致性初扫（中英混排处清理）。

验收：
- 后端停掉时每个数据页显示错误态而非「暂无」。
- 搜索能命中真实 Profile / Project / Memory 并跳转。
- 移动端开抽屉 → 点导航跳页 → 抽屉自动关闭。
- 桌面 ≥1024 无横向滚动；移动可操作核心表格。

## M2 · 逐页照图施工

**目标**：11 页逐一达到 `web-ux/03-页面规格.md`，**空/载/错态、删除确认、深色细节全部到位**。

顺序（按页面规格章节号）：
1. `login`
2. `dashboard`
3. `profiles`
4. `projects`
5. `memories`
6. `skills`
7. `usage`
8. `keys`
9. `providers`
10. `docs`
11. `settings`

每页子目标（以页规格为准，共性包括）：
- 空态组件化（`EmptyState`），不再是「空白表格」；
- 删除/禁用过 `ConfirmDialog`；
- StatCard 加载统一「—」（修复 usage 页显示 `0` 的闪变）；
- 图表走语义 token（修复 usage 深色下隐形）+ 空图占位；
- 表单控件统一（复用 `Select`/`Field`），provider 单值正确呈现为 deepseek 标签而非假多选；
- date 列与格式统一；docs 页示例值改为真实默认。

验收：
- 逐页对照 `web-ux/03` 检查项可勾选。
- 每页在 无数据 / 加载中 / 请求失败 / 正常 四态下都不白屏、不误导。

## M3 · 收口验收

**目标**：跑 `web-ux/05-验收清单.md`，全站一致性与可访问性达标。

内容：
- 深色 QA：每个页面 × 每个状态；usage 图表在深色下可见。
- 响应式 QA：桌面/平板/移动三档；关键页（dashboard、memories、usage）重点。
- 文案终扫：全站 zh-CN，领域词规范，无残留硬编码演示值。
- 键盘可达性：复制按钮、Dialog、表单均可 Tab 操作。
- 删除/禁用全链路确认存在。

验收：
- `web-ux/05-验收清单.md` 全勾（`[x]`）。
- Demo acceptance（`web-ux/05` §结尾）：评审者不读源码即可完成 登录 → 建 Project → 建 Profile → 建 API Key → 复制 Docs 连接 → 建全局与项目 Memory → Pin → 看 Usage 空/真实状态。

## 里程碑间依赖

- M1 依赖 M0（边界、错误态要组件/数据层支撑）。
- M2 每页依赖 M1（页面标题/搜索/主题已就绪）+ M0（组件）。
- M3 是纯验证收口。

> 注：本计划**只覆盖 apps/web**。API 网关 / Mem0 bridge / 云端部署不在本路线内（见仓库其他规划）。
