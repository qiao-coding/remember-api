# web-ux/01 · 现状审计（as-is 基线）

> **快照日期**：2026-09-05。审计对象：`apps/web`。file:line 为当日真实位置，**重做期间代码会变，引用会失效**——本文定位为「重做前基线证据」，施工时以最新代码为准，不再逐行同步。
>
> **一句话结论**：外壳与 Dashboard 是**可用的、成体系的**（Tailwind neutral 色、真实导航、深色 variant），但整体处于**半成品态**：无全局 loading/error 边界、5 个 CRUD 页缺空态、几处硬编码演示缝、深色覆盖不全、交互缺确认、中英文案混用、手写样式重复 6 页。

## 0. 技术栈现状（审计记录）

Next.js 15（App Router）+ React 19 + TypeScript；Tailwind CSS **3.4**（`darkMode: "media"`）；无组件库（无 shadcn/Radix，`class-variance-authority` 手写 `Button/Badge`）；`lucide-react` 图标、`recharts` 图表、React Query 取数；`@supabase/ssr` 认证。全局 CSS `globals.css` 用 `prefers-color-scheme` 媒体查询 + 组件内 `dark:` 双机制并存。无字体配置（系统栈）。`src/` 为空目录；实际代码在 `app/` `components/` `lib/`。

## 2. P1（明显粗糙，属一致性与完成度）

| # | 现象 | 证据 | 影响 |
|---|---|---|---|
| P1-1 | **顶栏搜索是纯装饰**：无 input handler / state | `components/app-shell.tsx:50-53` | 用户以为能搜，点了没反应 |
| P1-2 | **无主题手动切换**；globals.css 媒体查询与 `dark:` 双机制并存 | `app/globals.css`；tailwind.config `darkMode:"media"` | 无法切深色；两套深色机制偶发不一致 |

| P1-9 | **Checkbox 手写**：`<label className="flex h-9 items-center ...">` 重复 | profiles（skill 多选）/ memories | 无统一 Switch/Checkbox 组件 |
