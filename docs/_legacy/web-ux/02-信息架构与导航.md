# web-ux/02 · 信息架构与导航

> **取材来源**：`../_legacy/WEB-CONSOLE-UX.md`（IA/布局契约）、`../03-接口契约.md`（端点与路由）、`01-现状审计.md`（外壳现状）。
>
> **性质**：to-be 目标。重做后导航、布局、路由与全局状态的定义。

## 1. 导航（10 项 + 顺序）

侧栏主导航固定顺序，每项含图标与职责：

| 顺序 | 项 | 职责（job） |
|---|---|---|
| 1 | Dashboard | 一眼可知 API 使用状态：请求/token/成本/延迟 + 活跃资源一览 |
| 2 | Profiles | 管理客户端看到的 `model` |
| 3 | Projects | 项目上下文（摘要/架构/状态/决策/问题） |
| 4 | Memories | 记忆搜索/过滤/创建/编辑/删除/固定 |
| 5 | Skills | prompt fragment 管理 + token 估算 |
| 6 | Usage | 用量汇总、明细、breakdown、memory overhead |
| 7 | API Keys | `rma_` 调用密钥管理 |
| 8 | Providers | 供应商配置（当前 deepseek） |
| 9 | Docs | 客户端接入说明 |
| 10 | Settings | 账号与退出 |

> 顺序即心智模型：先「状态」→ 再「资源配置（Profile 为中心）」→「记忆/技能」→「成本」→「凭证/供应商」→「帮助/设置」。导航标签用**中文**（领域词保留：Profiles / Projects / Memories / Usage…）。

## 2. 布局契约

### 桌面（≥1024px）
- **侧栏**：固定左栏，宽 `w-64`（16rem），常驻显示全部 10 项导航 + 品牌「remember-api」。
- **顶栏**：当前页名 + 副题（如「OpenAI-compatible gateway control plane」）+ **可用的全局搜索**（见 §4）+ 用户 email（可含下拉）+ 深色切换。
- **内容区**：`lg:pl-64` 左侧留白；主内容 `max-w` 约 1440px；表格横向滚动**只限表格内部**（外包一层 `overflow-x-auto`），页面整体不错位。

### 移动（<1024px）
- 侧栏 off-canvas：默认 `-translate-x-full` 隐藏，顶部汉堡打开 + 半透明 backdrop。
- **路由变化自动关闭**：点导航跳页后抽屉必须收起（不依赖用户再点一次关闭）。
- 表单单列；表格保持可横向滚动。

### 卡片
- `Card` 只用于具体资源 / 表单 / 统计单元；**不把整个页面套进大卡**。圆角 8px、间距稳定（token 化）。

## 3. 路由与保护

| 路由 | 内容 | 保护 |
|---|---|---|
| `/login` | 登录卡（Supabase 密码登录） | 公开；已登录访问 → 跳 `/dashboard` |
| `/dashboard` | Dashboard | 需登录 |
| `/profiles` `/projects` `/memories` `/skills` `/usage` `/keys` `/providers` `/docs` `/settings` | 各资源页 | 需登录 |
| `/` | 首页 | 直接重定向 `/dashboard` |
| `/api` `/v1` | 后端直通（中间件放行，鉴权在服务端） | — |

- 未登录访问受保护页 → `/login?next=<path>`；登录后回跳 `next`。
- **全局边界**：`loading.tsx`（路由级骨架）、`error.tsx`（错误隔离，文案：**后端不可用/加载失败**，附重试，**绝不当空数据处理**）、`not-found.tsx`。
- 数据页请求失败的处理与路由级 error 一致（query 层 `isError` 也要渲染，不能静默）。

## 4. 全局搜索

- 位置：顶栏，桌面可见；移动端折叠进导航或隐藏。
- 范围与跳转：
  - 命中 **Profile**（name）→ `/profiles` 并高亮该行；
  - 命中 **Project**（name/description）→ `/projects` 并高亮；
  - 命中 **Memory**（content 关键词）→ `/memories?q=<keyword>`（复用该页搜索）。
- 交互：输入防抖 → 分组下拉候选（三类分节 + 计数）→ 键盘 ↑↓ 选择、Enter 跳转、Esc 关闭。
- 真实数据源：分别调 `/api/profiles`、`/api/projects`、`/api/memories?q=`（本地过滤或复用端点），**不做装饰输入框**（修 P1-1）。

## 5. 全局状态语义（统一口径）

| 状态 | 视觉 | 文案口径 |
|---|---|---|
| 加载 | `Skeleton` 或行内「加载中…」（表格行级 `TD` 提示） | — |
| 空 | `EmptyState` 组件：图标 + 标题 + 一句说明 +（可选）主操作 | 「还没有 Profile / 添加第一个」 |
| 错误 | 页面级 `error.tsx` 或面板内错误块 | 「加载失败，请确认后端服务可用」（区分「无数据」与「出错」） |
| 未连接 | Provider 未配 key → Badge「未连接」 | 提供跳转配置 |

## 6. 页面骨架（通用模板）

```
<PageHeader title="Profiles" description=… action="新建" />
<Table …>            ← 数据表（含 loading/empty/error 三态行）
<CreateOrEditDialog> ← 增改（Dialog，替代现内联 Card toggle）
<ConfirmDialog />    ← 删除/禁用确认
```

各页「建」的入口统一为顶栏右侧主按钮；行内操作为 编辑 / 更多（删除等）。表与表单字段以 `03-页面规格.md` 与 `../03-接口契约.md` 为准。
