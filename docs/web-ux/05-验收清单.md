# web-ux/05 · 验收清单（重做后签收）

> **取材来源**：`../_legacy/acceptance-checklist.md`（Web 节）、`../_legacy/WEB-CONSOLE-UX.md`（demo acceptance）、`01-现状审计.md`（修项回归）、`03-页面规格.md`（逐页验收）。
>
> **用法**：M3 收口时逐条勾。**全部 `[x]` 才算完工**。勾前必须真机操作（桌面 + 移动 + 深色）。

## A. 登录与路由保护

- [ ] 未登录访问任意受保护页 → 跳 `/login?next=<path>`，登录后回跳原页。
- [ ] 已登录访问 `/login` → 跳 `/dashboard`。
- [ ] 错误凭证登录 → 卡内中文错误，不跳转、无明文提示区分。
- [ ] 退出 → 回 `/login`，再访问受保护页不再放行。

## B. 全局四态与诚实状态（回归 P0-1/P0-2/P0-7）

- [ ] 每个数据页存在 加载 / 空 / 错误 / 正常 四态，均不白屏、不误导。
- [ ] **后端不可用**（停 Fastify）：数据页显示错误 + 重试，**不渲染成空表/「暂无」**。
- [ ] 路由级 `loading.tsx` / `error.tsx` / `not-found.tsx` 存在且生效。
- [ ] 全站 `StatCard` 加载为「—」（usage 页不再闪 `0`）。
- [ ] profiles / projects / skills / providers / keys 均有 `EmptyState`（非空白表格）。

## C. 深色与主题（回归 P0-3/P1-2）

- [ ] 默认跟随系统；顶栏可手动切浅/深，刷新保持。
- [ ] usage 图表在深色下可见（fill 用 token，无硬编码 hex）。
- [ ] 全部页面 × 表格/表单/卡片/图表在深浅两色下可读、无隐形元素。

## D. 页面验收（对照 `../03-页面规格.md`，逐页）

- [ ] **dashboard**：StatCards 与 `/api/usage/summary?days=7` 一致；四面板统一列表样式；各面板有 EmptyState。
- [ ] **profiles**：CRUD 可用；provider 为 deepseek 单值标签（无假多选）；project/skill 绑定下拉/复选来自真实数据；创建后 `/v1/models` 立即可见。
- [ ] **projects**：`decisions`/`knownIssues` 以列表编辑器往返；删除有确认并提示对 Profile 影响。
- [ ] **memories**：搜索显示 relevance；类型/归属/pinned 过滤正确；全局 vs 项目清晰区分；含日期列；固定态有文字不只图标；可编辑/删除。
- [ ] **skills**：创建/编辑后 token 估算更新；可显示被哪些 Profile 使用。
- [ ] **usage**：1/7/30 天窗口切换刷新；breakdown 可切 Profile/Project；空图有占位；成本单位 `¥`。
- [ ] **keys**：新建显明文一次 + 复制可达；禁用后 `/v1` 调用 401；刷新不复显；列表只有 prefix+last4。
- [ ] **providers**：行内编辑可用；key 不写回显；「已连接/未连接」正确；未配置有空态引导。
- [ ] **docs**：Base URL / API Key / Model 为真实值，复制后照抄可打通（无假 `remember-dev`、无硬编码 `localhost:4000` 当生产值）。
- [ ] **settings**：显示当前账号 email/name；可退出；无静态 env 名伪设置。

## E. 交互与安全护栏

- [ ] 所有删除/禁用操作必经 `ConfirmDialog`。
- [ ] 所有表单提交有 pending + 防重复提交；失败有 Toast/错误文案。
- [ ] API Key 明文只在创建瞬间可见（其余接口/列表均不可查）。

## F. 响应式与可访问性

- [ ] 桌面 ≥1024px：页面整体无横向滚动，表格滚动只限表内。
- [ ] 移动端：可开导航抽屉并操作核心表格；导航跳页后抽屉自动关闭。
- [ ] 键盘可达：复制按钮、Dialog、表单控件均可 Tab 操作；Dialog Esc 关闭。
- [ ] 无关键状态仅靠颜色/图标表达（Memory 固定有文字）。

## G. 文案与一致性

- [ ] 全站 zh-CN；领域词规范（Profile/Memory/API Key…）；无半中半英标签、无残留演示文案。
- [ ] 日期/时间格式统一；金额 `¥`；token 标注单位。

## H. Demo acceptance（评审者不读源码即可完成）

- [ ] 登录后台 → 进入 Dashboard。
- [ ] 创建 Project → 创建 Profile（绑 project、开 memory）→ 创建 API Key（复制明文）。
- [ ] 打开 Docs → 复制 Base URL / API Key / Model 三项。
- [ ] 创建一条全局 Memory + 一条项目 Memory → 搜索到 → Pin 一条。
- [ ] 打开 Usage：无数据见空状态，有数据见统计与明细。
- [ ] 桌面与移动宽度均无文字互相覆盖、无不可操作的主按钮。
