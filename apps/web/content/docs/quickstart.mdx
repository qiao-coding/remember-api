## 接入步骤

1. **填 Base URL** —— 网关的 OpenAI 兼容地址是 `<你的实例域名>/v1`，即本控制台所在的域名加 `/v1`。多数客户端把这一项叫「API 地址 / Base URL」。
2. **填 API Key** —— 在控制台「API Keys」新建一个（明文只显示一次，立即复制）。每个 key 都绑定一个个人 model（子 agent），只能调用它那一个。
3. **填 Model** —— 模型名填你的「个人 model」名——也就是控制台「Profiles」里建的那个名字，`/v1/models` 里列出的就是。客户端固定填被绑的那个 profile 名即可。
4. **发起调用** —— 填完即可对话。同一份记忆与偏好会自动注入回答，并随对话沉淀，所有接入的客户端共享；流式（SSE）原生支持。

> **不用学新东西**：绝大多数 AI 客户端原生支持 OpenAI 兼容接口，把网关当成一个普通的模型供应商填进去就行，无需额外 SDK 或插件。
